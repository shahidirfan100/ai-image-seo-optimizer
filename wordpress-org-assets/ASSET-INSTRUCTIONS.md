# WordPress.org Asset Upload Guide

Upload these files to the plugin's WordPress.org SVN `assets` directory, not the plugin `trunk` directory:

- `icon-128x128.png`
- `icon-256x256.png`
- `banner-772x250.png`
- `banner-1544x500.png`
- `screenshot-1.png`
- `screenshot-2.png`
- `screenshot-3.png`

The screenshot order matches the `== Screenshots ==` section in the plugin's `readme.txt`.

Do not copy these promotional assets into the plugin ZIP. Keeping them in the WordPress.org `assets` directory avoids unnecessary plugin download weight.
